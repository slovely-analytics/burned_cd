# Survivor Pool Strategizer

A private collaborative decision tool for two partners managing their own entries in an NFL survivor pool. The partners coordinate picks across all of their entries, attempt to keep at least one entry alive through the season, and split any winnings.

The project source of truth is [docs/PRODUCT_BRIEF.md](docs/PRODUCT_BRIEF.md). Original pool rules and their searchable transcription are preserved in [source/context](source/context).

## Product Direction

The recommended product is a mobile-friendly collaborative web app. It should provide one shared view of every entry, each entry's team-use history, the current week's candidate picks, and a coordinated portfolio recommendation.

The tool should support decisions; it should not submit picks to Splash automatically. Final pick submission and confirmation remain with the two partners.
